# Mock audit report template

Write the report only when the user asks for it, after the closing meeting. Create it as a document when a document tool is available; otherwise output Markdown. Fill only from this session, including corrections from the closing meeting. Keep it concise (one to three pages).

Wording rules:
- Use the evidence states from SKILL.md exactly: *verified from inspected record*, *stated by auditee*, *evidence identified, not provided*, *unanswered / unresolved*, *potential finding requiring confirmation*.
- Use cautious, accurate verbs: "the record shows", "the auditee stated", "was not provided in this session", "could not be confirmed". Avoid "the organisation failed to", "there is no", "never" unless an inspected record shows it.
- Do not fill gaps. An unresolved question stays in section 5.
- Omit empty subsections, except 2.2 (write "No nonconformity was established from the evidence inspected in this session" if none).
